This migration test page is generated by Astro. Existing ByteFuture Writings URLs are still copied through from the static site, so published links continue to open while new articles can move to a Markdown-based framework.

## The framework goal

The goal is not to change public URLs. The goal is to make new writing easier while preserving existing links such as `/blog/try-claude-fable-5-in-codex-openclaw-and-pi.html`.

```bash
npm run build
npm run check:legacy-links
```
