연구 2026년 6월 15일

GLM-5.2가 Z.AI 주가를 33% 끌어올렸다. 이제 Token Station에서 무료로 써 보세요

GLM-5.2는 평범해 보이던 모델 공개를 시장을 뒤흔든 사건으로 바꿔 놓았다. 6월 15일, Zhipu AI의 홍콩 상장 주식은 장중 한때 48%까지 올라 1,620홍콩달러를 찍었고, 32.8% 상승한 1,457홍콩달러로 마감했다.

이 주식은 1월 초 Zhipu의 IPO 이후 약 820% 올랐다. JP모건은 목표주가를 1,400홍콩달러로 올리며 「비중확대」 의견을 유지했고, 뱅크오브아메리카는 「매수」로 커버리지를 시작했다. 버전 업데이트가 기업을 이 정도로 움직이는 일은 흔치 않다. 이번에는 그런 일이 일어났다.

달러로 환산하면 규모가 분명해진다. GLM-5.2 공개 전날 Z.AI 상장 주식의 시가총액은 약 600억 달러였다. 이번 공개는 단 하루 만에 200억 달러 가까이를 더해 회사를 약 800억 달러, 즉 Airbnb와 비슷한 규모로 끌어올렸다. 가장 쉬운 잣대는 Coinbase로, 2026년 6월 중순 기준 시가총액이 약 420억 달러다. GLM-5.2는 하루 만에 Z.AI를 「Coinbase 약 1.5개」에서 「거의 2개」로 키웠다. 이제 코딩 모델 하나의 공개가 미국 기술 우량주 규모의 회사를 움직이고 있다.

주가가 움직인 이유

GLM-5.2는 Z.AI의 새로운 플래그십 코딩 모델이며, 그 공개를 각주가 아닌 시장의 화제로 만든 요인이 두 가지 있다.

첫째, 이 모델은 오픈소스다. MIT 라이선스로 공개되었고 100만 토큰 컨텍스트 윈도우를 갖췄으며 장기 호흡의 에이전트 코딩에 초점을 맞춘다. 이는 폐쇄형 최전선을 꾸준히 따라잡아 온 계보를 잇는다. GLM-5는 SWE-bench Verified에서 77.8%를 기록했고, 이후 릴리스마다 격차를 좁혀 왔다. 가중치를 내려받을 수 있으므로 이 역량은 회수될 수 없다.

둘째, 타이밍이다. GLM-5.2가 등장한 바로 그 주말, 미국의 수출 통제 명령으로 Anthropic은 가장 강력한 두 모델인 Claude Fable 5와 Mythos 5를 모든 사용자에게 중단해야 했다. 한 최전선 업체가 정부 지시로 멈춰 섰다. 그 사이 최전선급 컨텍스트 윈도우를 갖춘 오픈 모델이 Anthropic 최상위 Claude Code 및 Max 등급의 약 10분의 1 가격으로 등장했다. 투자자들은 이를 중국 오픈 모델이 그 공백을 메우고 있다고 해석했고, 그런 모델을 내놓는 회사를 다시 평가했다.

이 상승세가 이어질지는 시장이 답할 문제다. 개발자에게 더 쓸모 있는 질문은 더 좁다. 그 뒤에 있는 모델이 당신의 코드에서 실제로 쓸 만한가? 답을 찾으려고 주식을 살 필요는 없다.

Token Station에서 GLM-5.2 무료로 사용하기

GLM-5.2는 Token Station에서 glm/glm-5.2로 제공되며, 100만 토큰의 전체 컨텍스트를 지원하고 Z.AI의 정가에 마진 없이 과금된다. 입력 100만 토큰당 1.40달러, 출력 100만 토큰당 4.40달러다. 예산에서 한 가지 감안할 점이 있다. 사고가 항상 켜져 있어 추론 토큰이 출력으로 과금된다.

시작은 무료다. 가입하면 1달러 크레딧이 주어지며, 카드도 필요 없고 Z.AI 계정이나 Coding Plan 구독을 따로 만들 필요도 없다. 첫 충전 시 최대 50달러의 보너스 크레딧이 추가된다. 이미 쓰고 있는 코딩 도구를 glm/glm-5.2로 향하게 하고 실제 작업을 그대로 돌려 보면 된다.

Claude Code

Claude Code는 모델과 엔드포인트를 환경 변수에서 읽는다. 모든 등급을 Token Station을 통해 GLM-5.2로 라우팅한다.

export ANTHROPIC_BASE_URL="https://models.bytefuture.ai"
export ANTHROPIC_AUTH_TOKEN="gw-YOUR_TOKEN_STATION_KEY"

export ANTHROPIC_DEFAULT_OPUS_MODEL="glm/glm-5.2"
export ANTHROPIC_DEFAULT_SONNET_MODEL="glm/glm-5.2"
export ANTHROPIC_DEFAULT_HAIKU_MODEL="glm/glm-5.2"
export CLAUDE_CODE_SUBAGENT_MODEL="glm/glm-5.2"

Codex

Token Station을 provider로 설정하고 GLM-5.2를 모델로 지정한다.

mkdir -p ~/.codex
cat > ~/.codex/config.toml <<'EOF'
model = "glm/glm-5.2"
model_provider = "token_station"

[model_providers.token_station]
name = "token_station"
base_url = "https://models.bytefuture.ai/v1"
env_key = "TOKEN_STATION_API_KEY"
wire_api = "responses"
EOF

export TOKEN_STATION_API_KEY="gw-YOUR_TOKEN_STATION_KEY"
codex

OpenClaw

Token Station을 provider로 등록하고 GLM-5.2를 기본 모델로 설정한다.

{
  "models": {
    "mode": "merge",
    "providers": {
      "token-station": {
        "baseUrl": "https://models.bytefuture.ai/v1",
        "apiKey": "${TOKEN_STATION_API_KEY}",
        "api": "anthropic-messages",
        "models": [
          {
            "id": "glm/glm-5.2",
            "name": "GLM-5.2 (Token Station)",
            "contextWindow": 1000000,
            "maxTokens": 131072
          }
        ]
      }
    }
  },
  "agents": {
    "defaults": {
      "model": { "primary": "token-station/glm/glm-5.2" }
    }
  }
}

키 하나, 이미 쓰고 있는 도구, 그리고 방금 시장이 다시 평가한 모델. GLM-5.2가 당신의 저장소에서 통한다면, 그것을 확인하는 비용은 무료 가입뿐이다. 통하지 않으면 설정 한 줄만 바꾸고 넘어가면 된다.
